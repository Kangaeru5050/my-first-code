# TANAHAKO

棚または引き出しの内寸から、収納箱の外寸と内寸を計算する先生向け限定テスト版です。寸法に近い市販品を探すか、3Dプリント用STLを作るか、両方を組み合わせられます。`index.html` をブラウザーで開くだけで使えます。GitHub Pagesでも動きます。入力した寸法は送信・保存しません。

## できること

- 最初に使用するプリンターを選択し、箱1個が造形範囲に収まるか判定
- 「プリンターを使わない・市販品を探す」設定でも寸法設計を継続
- 「棚に並べる」「引き出しを整理する」の2モードから選択
- 算出した外寸を検索語に入れたWeb・楽天市場・Yahoo!ショッピングへの検索リンクを表示
- 市販品で合う寸法は購入し、見つからない寸法だけSTLで作る組み合わせに対応
- 棚モードでは同じ箱を横一列に並べ、箱1個分のSTLと必要個数を表示
- 引き出しモードは未分割の引き出し全体から開始し、図をクリックして縦線・横線を追加
- 分割線はクリックした区画の中だけに入り、左3段・右2段などの不均等配置にも対応
- 各小箱に外寸を表示し、分割線を選んで上下左右へ1 mmずつ動かして微調整
- 分割操作の「1つ戻す」と、1箱から作り直すリセットに対応
- 引き出し用の同寸法モデルをまとめ、STLの種類と印刷個数を表示
- 棚の幅・奥行・高さと、横に並べる箱の個数を入力
- 棚の端の余白、箱どうしのすき間、壁厚、底厚、箱の高さを指定
- 箱1個の外寸・内寸・必要個数と、棚の上面図を表示
- 箱1個が造形範囲に収まるかを、底を下にした通常向きと90°回転で判定
- 必要個数すべてを同時に載せる必要はなく、1個ずつ印刷できることを案内
- 完成プレビューに、寸法比を崩さない上面図とオプションを確認できる立体図を併記
- Bambu Lab P1S（造形範囲256 × 256 × 256 mm）をプリンターの初期設定として使用
- ふたのない箱をSTLとして直接ダウンロードし、Bambu Studioなどのスライサーで開く
- 背面中央のケーブル穴を、幅・高さ・底からの位置を指定してSTLに反映
- 前面上端に、幅と深さを指定した指掛けの切り欠きを追加
- 紙を上から差し込める前面ラベルポケットを追加
- ラベル差しの正面をコの字型にし、不透明フィラメントでも紙の中央が見える構造に変更
- ラベルポケット下に約45度の補強を設け、サポートなし造形時の荒れを軽減
- 初めて使う人向けに「場所を選ぶ→内寸を測る→買う・作る」の3ステップを表示
- 外箱・ケーブル穴・指掛け・ラベル差しを反映する立体プレビューを表示
- 立体プレビューを、奥側が上・手前側が下になる俯瞰表示に調整
- 立体プレビューの幅方向を水平にし、底が傾いて見えない投影に修正
- 「箱1個」と「棚に並べる別々の箱」を見出し・説明・箱番号で区別
- 透明な立体プレビューの底板を外壁の底面四隅に揃え、ずれて見える問題を修正
- 壁面を半透明化し、壁厚の内外線を透視表示（壁厚は視認性のため強調）
- 内部仕切り機能を削除し、棚に独立した箱を並べる用途へ整理
- ラベルポケットの張り出しを含めてプリンターの造形範囲を判定
- 全オプションを100 × 70 × 50 mmで確認できる「機能見本STL」を出力
- 編集用のOpenSCADファイルもダウンロード

## 計算

横方向の外寸 = `(棚の幅 - 端の余白×2 - 箱のすき間×(横の個数-1)) / 横の個数`。奥行も同様です。造形時に棚からはみ出さないよう、外寸を0.1 mm単位で切り捨てます。その結果、端の余白は入力値より少し大きくなることがあります。内寸は外寸の幅と奥行から壁厚の2倍、高さから底厚を引きます。箱の高さは既定で棚の高さから10 mmを引きます。

計算値は設計上の寸法です。造形誤差、棚のゆがみ、ブリム、サポート、積み重ねの強度は含みません。

## 公開

この試作版は `my-first-code` リポジトリの `tanahako/` フォルダーにあります。GitHub Pagesで公開する場合は、リポジトリの Settings → Pages で公開元を `main` ブランチの `/ (root)` に指定すると、`https://kangaeru5050.github.io/my-first-code/tanahako/` から開けます。公開設定が完了するまではリンクは表示されません。

先生だけに試してもらう段階では、`TANAHAKO-teacher-beta-v21.html` を共有し、ダウンロード後にChromeなどで開いてもらえます。寸法計算とSTL生成はオフラインでも動きます。市販品検索リンクだけはインターネット接続が必要です。
