# ことログ

声と食事写真で続ける、日本語の体重・生活記録アプリ。ビルド不要のHTML/CSS/JavaScriptで動きます。

## 機能
- 6問の初回設定（全項目をスキップ可能・後から変更可能）
- ブラウザーのSpeechRecognitionによる音声入力、対応しない端末ではキーボードの音声入力
- 声の文章から体重・睡眠・食事区分・昨日の日付を抽出し、保存前に確認
- カメラ／写真選択、写真圧縮、メモと一緒に保存
- 日付・記録の編集と削除、体重グラフ、7日間の記録に基づく振り返り
- 写真を含むJSONバックアップ・重複IDを統合する復元

## データと制限
記録はIndexedDBでブラウザー内に保存され、GitHubやアプリのサーバーには送信しません。写真の加工も端末内で行います。音声認識はブラウザー提供元に音声が送られる場合があります。音声認識はブラウザー・端末・権限により動作が異なります。

AIによる写真の食材・量・カロリー判定、クラウド同期、通知、個別の医療・栄養指導は未実装です。数値抽出はルールによる処理で、保存前の本人確認を前提とします。ブラウザーのデータ削除や端末変更に備え、バックアップを保存してください。初回の配慮事項はメモとして保存します。

## 実行
`dist/`をHTTPS対応の静的ホスティングに配置してください。開発時はローカルの静的HTTPサーバーで開きます。音声認識にはHTTPSまたはlocalhostとマイクの許可が必要です。

## 検証
`node tests/core.test.cjs`で、日本語の数値抽出・日付・インポート検証・HTMLエスケープを確認できます。端末実機での音声・カメラ・IndexedDB保存の確認は別途必要です。
